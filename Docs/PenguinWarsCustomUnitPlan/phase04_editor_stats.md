# Phase 4: 作成画面の「のうりょく」タブ

## ゴール

作成画面の「のうりょく」タブで、役割・コスト・強化レベル・範囲攻撃・能力を決められる。コストを動かすと段階が変わり、触れる数値・強化ポイント・能力枠・範囲攻撃が増えたり減ったりする。結果の数値（体力・攻撃・射程・速度・再生産）がその場で分かる。

## 読むもの

* INDEX の「仕様（コストの段階）」
* Phase 1・3 の引き継ぎメモ（`CustomUnitRules` の API・`CustomUnitPanel` の作り）
* 既存コード: `UnitLabels.cs`（役割・能力の表示名）、`ZukanDetailPanel.cs`（数値の並べ方）

## 画面

```text
[ みため ][ のうりょく ]
役割   [ アタッカー ▼ ]
コスト 200 ━━━━●━━━━ 600   400   段階 ●●○
強化ポイント  のこり 0 / 3        能力枠 1

体力   [-] ■■□□□ [+]  ×1.1   380 → 420
攻撃   [-] ■□□□□ [+]  ×1.1    47 → 52
速度   [-] ■□□□□ [+]  ×1.1   1.10 → 1.21
再生産 [-] □□□□□ [+]  ×1.0   8.0秒
射程   🔒 コスト 500 から

範囲攻撃 🔒 コスト 500 から
能力   [ ふっとばす ▼ ]   [ 🔒 ]
```

* 役割を変えたら、コストは新しい役割の帯の **同じ位置（t）** に寄せ、`Sanitize` を通す（段階がなるべく変わらないように）
* コストのスライダーは刻み（壁10・ほか50）で止まる。動かすたびに `Sanitize` → 画面を作り直す
* 段階が下がってレベルや能力が外れたら、画面上部に1行「コストが下がったので ○○ をもどしました」を2秒出す（黙って消えると驚くため）
* `[-]` は -2 まで、`[+]` は +3 まで・ポイントが残っている間だけ押せる。ゲージはマイナスを別の色で表す
* 🔒 の行は「コスト N から」と、解放されるコストを出す（何を上げれば触れるか分かるように）
* 右端は「式のままの値 → 強化後の値」。ずかんと同じ単位・桁で出す
* 能力のドロップダウンは8種＋「なし」。同じ能力は2つ目の枠で選べない
* 能力・範囲攻撃を付けると体力・火力が下がること（×0.9・×0.75）は、数値がその場で下がるので文章では説明しない

## 作るもの

| ファイル | 内容 |
| --- | --- |
| `Scripts/UI/CustomStatsTab.cs` | タブ全体。値が変わったら `CustomUnitRules.Sanitize` を通して `Changed` イベント |
| `Scripts/UI/CustomStatRow.cs` | 1行（名前・[-]・ゲージ・[+]・倍率・数値・🔒表示）。5行で使い回す |
| `CustomUnitPanel`（変更） | 左下の数値表示をのうりょくタブの変更に追従させる。プレビューは強さが変わっても作り直さない（見た目が変わらないため） |
| `Editor/PenguinWarsSceneBuilder.Custom.cs`（変更） | のうりょくタブの生成 |

## 実装メモ

* 画面の状態は持たず、毎回 `CustomUnitDefinition` から描き直す（`Sanitize` が直した結果がそのまま画面に出るので、画面と保存がずれない）
* 「どの段階で何が解放されるか」は画面に直接書かず、`CustomUnitRules` に問い合わせる（数値を変えても画面を直さずに済む）
* 範囲攻撃は段階3でだけトグルが押せる

## やらないこと

対戦での選択（Phase 5）、攻撃間隔・発生・ノックバック回数を変える機能、能力の確率を変える機能。

## 完了条件

* [ ] コストを上げ下げすると、触れる数値・ポイント・能力枠・範囲攻撃がINDEXの表どおり増減する
* [ ] 段階が下がったときに外れたものが1行で知らされる
* [ ] 保存して開き直すと同じ値が出る。数値表示が Phase 1 のテストの計算と一致する
* [ ] 既存の EditMode テストが通る

## ユーザー確認手順

1. 再生 → じぶんペンギン → のうりょく
2. 壁・遠距離・大型でコストを端から端まで動かし、解放のされ方が分かりやすいか
3. 「強すぎる組み合わせ」が作れそうなら伝える（Phase 6 で数値を見直す）
