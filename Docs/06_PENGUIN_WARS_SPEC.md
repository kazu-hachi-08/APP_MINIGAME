# 第6弾ミニゲーム：ペンギン大戦争 仕様書

## 1. 概要

「週末2人開発 2Dミニゲームプロジェクト」の第6弾ミニゲーム。にゃんこ大戦争風の横スクロール型タワーディフェンス。ペンギンを出撃させて敵の大群を食い止める。

| 項目 | 内容 |
| --- | --- |
| ジャンル | 横スクロール タワーディフェンス（にゃんこ大戦争風） |
| 視点 | 横から見た視点（Side View）・横画面固定 |
| グラフィック | 2Dピクセルアート（コードで生成するペンギン） |
| プレイ人数 | 1人（CPUエンドレス）/ 2人（オンライン1対1の城攻め。§10） |
| 味方キャラ | 全50体（ペンギンのバリエーション。§5） |
| 編成 | 10体（5体×2ページ） |
| 対象プラットフォーム | Android / iPhone（PCはマウス＋キーボードで確認用・ブラウザ版） |
| エンジン / 言語 | Unity / C# |

ソースは `Assets/_Project/Games/06_PenguinWars/`。Sceneは他のゲームと同じく `Tools > MiniGame > Rebuild PenguinWars`（`PenguinWarsSceneBuilder`）でコードから生成する。

> **実装計画:** [PenguinWarsPlan/00_INDEX.md](PenguinWarsPlan/00_INDEX.md)（全12フェーズ。「この仕様書からフェーズN進めて」と言われたら、まずこのINDEXを読んで手順に従う）

### 1.1 モード

| モード | 編成の決め方 | 相手 | ゴール |
| --- | --- | --- | --- |
| エンドレス（CPU） | 毎回ランダムに10体 | 右端の出現ゲートから無限に湧く敵ペンギン | 自城が落ちるまでの生存時間を競う |
| オンライン対戦 | ドラフト（3体から1体選ぶ×10回） | 相手プレイヤー | 相手の城を先に落とす（最大5分） |

## 2. ルール・試合の流れ

### 2.1 エンドレス

```text
モード選択（エンドレス / 部屋を作る / コードで参加）
  ↓
編成発表（ランダム10体を表示・2.0秒）
  ↓
START!（1.0秒）
  ↓
プレイ（経過時間が増える。30秒ごとに敵レベルUP）
  ↓
自城HP 0 → 城が崩れる演出（1.5秒）→ リザルト（生存時間・撃破数・ベスト記録）
```

* 敵側に城はない。右端の「出現ゲート」は無敵で、攻撃対象にならない（ゲートより右には進めない）
* ベスト記録（生存時間）は `PlayerPrefs` に保存する
* ランダム編成は全50体からの重複なし抽選。ただし「低コスト（壁役）が最低2体」入るようにする（壁がいないと序盤で詰むため）

### 2.2 オンライン対戦

```text
モード選択 → 部屋を作る / コードで参加 → 接続
  ↓
ドラフト（§6。10ラウンド）
  ↓
編成確認（お互いの10体を表示・3.0秒）
  ↓
START!（1.0秒）
  ↓
プレイ（残り時間が減る。最大5分）
  ├ どちらかの城HP 0 → 城が崩れる演出 → リザルト
  └ 残り0秒 → TIME UP → 城の残りHP割合が多い方の勝ち（同じなら引き分け）→ リザルト
```

* ホストは左（青ペンギン）、ゲストは右（赤ペンギン）。各自の画面では自分が左に来るよう反転表示する（§10.3）

### 2.3 勝敗

| 結果 | リザルトのタイトル | 詳細 |
| --- | --- | --- |
| エンドレス終了 | GAME OVER | 生存 mm:ss / 撃破 N体（ベスト更新時は NEW RECORD!） |
| 対戦で勝ち | VICTORY! | 勝利！ |
| 対戦で負け | GAME OVER | 敗北... |
| 対戦で引き分け | DRAW | 引き分け |

リザルトからリトライ（エンドレスはScene再読み込み、対戦はモード選択へ）またはタイトルへ戻れる。

### 2.4 ゲーム状態

| 状態 | 内容 |
| --- | --- |
| `Draft` | ドラフト中（オンラインのみ） |
| `Intro` | 編成発表・START! 表示 |
| `Playing` | プレイ中。時間・お金が進む |
| `Finished` | 城崩れ演出〜リザルト |

## 3. 戦場

### 3.1 レーン

* 地面は1本の横レーン（にゃんこと同じく上下移動なし）。ユニットはX座標だけで管理する
* 戦場の長さ `_fieldLength = 30`（ワールド単位）。左端に自城、右端に敵城（エンドレスは出現ゲート）
* 物理演算（Rigidbody2D / Collider）は使わず、X座標の比較だけで当たり判定・射程判定をする（オンラインで結果がずれず、処理も軽いため）

### 3.2 カメラ

* 画面に映るのは戦場の約半分。ドラッグ（PCはドラッグまたは ←→ キー）で横スクロールする
* 開始時は自城側を映す

### 3.3 城

| 項目 | 値（初期案） |
| --- | --- |
| 城HP（エンドレス） | 3000 |
| 城HP（対戦・両者） | 5000 |

城もユニットと同じく「X座標を持つ攻撃対象」として扱う。城は攻撃しない（攻撃手段は §4.4 のペンギン砲のみ）。

## 4. お金・生産・ペンギン砲

### 4.1 お金（さかな）

ペンギンらしく通貨は「さかな」。

* 時間で自動的に増える ＋ 敵を倒すと増える（敵のコストの 50%）
* 上限と増える速さは「働きペンギン」のレベルで決まる

### 4.2 働きペンギン（財布レベル）

画面左下のボタン。さかなを払うとレベルが上がり、上限と増える速さが上がる（本家の「働きネコ」）。

| レベル | 上限 | 増える速さ（/秒） | 次のレベルに必要 |
| --- | --- | --- | --- |
| 1 | 500 | 30 | 80 |
| 2 | 800 | 40 | 160 |
| 3 | 1100 | 50 | 240 |
| 4 | 1400 | 60 | 320 |
| 5 | 1700 | 70 | 400 |
| 6 | 2000 | 80 | 480 |
| 7 | 2300 | 90 | 560 |
| 8（最大） | 2600 | 100 | — |

数値は `PenguinWarsBalance`（ScriptableObject）に置き、遊びながら調整する。

### 4.3 出撃

* キャラボタンをタップ → さかなが足りて再生産時間が終わっていれば、自城の前に出撃
* 出撃後、そのキャラは再生産時間（クールダウン）中は出せない。ボタンに残り時間ゲージを表示
* 場に出せる自軍ユニットの上限は 30体（スマホの処理負荷対策）

### 4.4 ペンギン砲

画面右下のボタン。チャージ式の城の必殺技（本家の「にゃんこ砲」）。

| 項目 | 値（初期案） |
| --- | --- |
| チャージ時間 | 40秒（開始時は0から） |
| 効果範囲 | 自城から戦場の 60% までの敵全員 |
| 効果 | ダメージ 100 ＋ ノックバック1回分（§5.4） |

チャージ完了時にボタンが光る。オンラインでは両者が持つ。

## 5. ユニット

### 5.1 データの持ち方

1体ごとに `PenguinUnitData`（ScriptableObject）を作る。50体分のアセットを `Data/Units/` に並べ、`PenguinUnitCatalog`（ScriptableObject）で一覧を持つ。キャラ追加はアセットを増やすだけで済むようにする（2人で別々のキャラを足してもコンフリクトしないため）。

| 項目 | 内容 |
| --- | --- |
| `Id` / `DisplayName` | 識別子 / 表示名 |
| `Cost` | 出撃に必要なさかな |
| `Cooldown` | 再生産時間（秒） |
| `MaxHp` | 体力 |
| `Attack` | 1回の攻撃力 |
| `Range` | 射程（自分の位置から前方） |
| `AttackInterval` | 攻撃間隔（秒） |
| `Windup` | 攻撃発生までの時間（秒）。本家の「攻撃発生」 |
| `MoveSpeed` | 移動速度 |
| `IsAreaAttack` | 範囲攻撃（射程内の全員）か単体攻撃（一番前の1体）か |
| `KnockbackCount` | 倒れるまでにノックバックする回数（§5.4） |
| `Abilities` | 特殊能力（§5.3。複数可） |
| `Look` | 見た目パーツ指定（§7.2） |

### 5.2 行動

```text
前進
  ↓ 射程内に敵ユニット or 敵城が入った
攻撃（Windup 待ち → ダメージ → AttackInterval 待ち）を繰り返す
  ↓ 射程内に敵がいなくなった
前進に戻る
```

* 単体攻撃の対象は「射程内で一番こちら側に近い敵」
* 攻撃中にノックバックされたら攻撃はキャンセル

### 5.3 特殊能力（5種）

| 能力 | 効果 | パラメータ |
| --- | --- | --- |
| ふっとばす | 攻撃が当たると確率で相手をノックバックさせる | 確率 |
| 止める | 攻撃が当たると確率で相手の動き・攻撃を一定時間止める | 確率・秒数 |
| 遅くする | 攻撃が当たると確率で相手の移動速度を一定時間半分にする | 確率・秒数 |
| 城キラー | 城へのダメージが3倍 | — |
| ふんばる | ノックバックしない（体力が減っても後ろに飛ばされない） | — |

> 本家の「打たれ強い」「めっぽう強い」は敵の属性（赤い敵・浮いてる敵など）が前提の能力。このゲームは敵も同じペンギン（属性なし）なので、代わりに属性がなくても意味を持つ「城キラー」「ふんばる」にした。

### 5.4 ノックバック

* 体力が「最大HP ÷ KnockbackCount」減るごとに1回ノックバックする（後ろに 1.5 飛ばされ、0.5秒動けない）
* 「ふっとばす」・ペンギン砲でも同じノックバックが起きる
* HP 0 で倒れる（その場で消えるアニメ → 削除）

### 5.5 キャラ一覧（初期案・50体）

## 6. ドラフト（オンラインのみ）

```text
ラウンド1〜10:
  各プレイヤーに、全50体からランダムな3体を提示（自分が既に取ったキャラは出ない）
  両者が同時に1体を選ぶ（制限時間15秒。過ぎたら3体からランダム）
  両者が選び終わったら次のラウンドへ
```

* 提示はプレイヤーごとに別々。相手と同じキャラを取っても構わない（被りあり）
* 抽選はホストが行い、ゲストに提示内容を送る（乱数のずれを防ぐため）
* 相手が何を取ったかはドラフト中は見えない。終了後の「編成確認」でお互いの10体を公開する
* 画面: 中央に3枚のカード（見た目・名前・コスト・役割・能力）、上にラウンド数と残り時間、下に取ったキャラの一覧

## 7. 画面・ビジュアル

### 7.1 画面レイアウト（横画面）

```text
┌───────────────────────────────────────────┐
│ 自城HP ████      [生存 01:23 / 残り 3:20]     敵城HP ████ │
│                                                         │
│  🏰  🐧🐧 🐧         ←→        🐧🐧    🚪/🏰           │  ← 戦場（横スクロール）
│ ─────────────────────────────────────────────────────── │
│ [働き Lv3]  [1][2][3][4][5]  [⇄]          [ペンギン砲] │
│  さかな 420/1100                                        │
└───────────────────────────────────────────┘
```

* キャラボタンは5個×2ページ。`[⇄]` でページ切り替え
* ボタンには見た目アイコン・コスト・再生産ゲージ。出せないときは暗くする
* PC: クリック、または数字キー 1〜5 で出撃・Tab でページ切り替え・Q で働きペンギン・Space でペンギン砲

### 7.2 ペンギンの見た目

ドット絵はコードで生成する（他のゲームと同じ方式）。50体を手描きせず、**基本ペンギン＋パーツの組み合わせ**で作る。

| パーツ | 例 |
| --- | --- |
| 体の形 | 基本 / 横長 / 縦長 / まんまる / 小さい / 拡大（2倍・3倍） |
| 体の色 | 黒白（標準）/ 水色 / 灰色 / 虹色 など |
| 頭 | ヘルメット / 王冠 / とんがり帽子 / ちょんまげ / 黒ずきん |
| 手に持つもの | 剣 / 斧 / 弓 / 魚 / ハンマー / 大砲 |
| 背中・乗り物 | ロケット / 冷凍庫 / バイク / クジラ |

* 敵（エンドレスのCPU、対戦の相手）は同じ見た目で体の黒い部分を赤系にした色違い。味方は青系
* アニメは「歩き（2コマ）」「攻撃（2コマ）」「ノックバック（1コマ）」の最小構成

### 7.3 城

* 自城：氷のお城（青）。敵城：同じ形の赤いお城。エンドレスの出現ゲート：洞窟の入り口

## 8. エンドレスの敵

### 8.1 敵レベル

30秒ごとにレベルが1上がる。

| 項目 | 内容 |
| --- | --- |
| 出現間隔 | レベル1: 4.0秒 → レベルごとに ×0.9（下限 0.8秒） |
| 出現するキャラ | 全50体のうち「コスト ≦ 300 + レベル × 250」のキャラからランダム |
| 体力・攻撃の倍率 | 1.0 + レベル × 0.15 |

* 敵は味方と同じ `PenguinUnitData` を使う（データを二重に作らないため）
* 一定レベルごと（5の倍数）に大型キャラを1体確定で出す（盛り上がりの山を作るため）

### 8.2 撃破報酬

敵を倒すと、そのキャラのコストの 50% のさかなが入る（倍率はかけない）。

## 10. オンライン対戦

### 10.1 方針

サッカー・卓球と同じく、参加コードを共有して離れた2人が1対1で対戦する。接続部分（`OnlineSession` / `ModeSelectPanel`）は `Assets/_Project/Common/Scripts/Online/` の共通処理を使う。

```text
モード選択
 ├ エンドレス → 編成発表 → プレイ
 ├ 部屋を作る → 参加コード表示 → 相手の参加待ち → ドラフト → 対戦（ホスト・左・青）
 └ コードで参加 → 接続 → ドラフト → 対戦（ゲスト・右・赤）
```

### 10.2 同期の考え方

サッカーと同じく **ホストだけが戦闘を計算し、ゲストは操作を送って表示するだけ** にする。

```text
ゲスト：ボタン操作（出撃・働きペンギン・ペンギン砲）を送る
  ↓
ホスト：両者のお金・出撃・ユニットの移動・攻撃・ノックバック・城HP・時間をすべて計算
  ↓
ホスト：全ユニットの状態と両者のお金・城HPを毎秒約15回送る
  ↓
ゲスト：届いた状態へ滑らかに寄せて表示
```

| 送る内容 | 向き | 配信 |
| --- | --- | --- |
| 全ユニットの ID・キャラNo・陣営・X座標・HP割合・状態（歩き/攻撃/ノックバック）、両者のさかな・財布Lv・城HP・砲チャージ・再生産残り、残り時間 | ホスト → ゲスト | 再送なし（古いものは捨てる）。約15回/秒 |
| ドラフトの提示内容・ラウンド進行、出撃音・撃破・砲発射などの演出、試合終了 | ホスト → ゲスト | 再送あり |
| 出撃（ボタン番号）・働きペンギン・ペンギン砲・ドラフトの選択 | ゲスト → ホスト | 再送あり（取りこぼすと操作が効かないため） |

* NetworkObjectは使わず、名前付きメッセージだけで送る（サッカーと同じ理由）
* ユニットは横1列で動きが単純なので、サッカーより送信回数を減らしても違和感が少ない

### 10.3 視点

ゲストの画面は左右を反転して表示し、自分の城が常に左に来るようにする（操作の感覚を揃えるため）。計算上の座標はホスト基準のまま。

### 10.4 その他のルール

* 相手が切断したら「相手が切断しました」を表示してリザルト（勝ち扱い）へ
