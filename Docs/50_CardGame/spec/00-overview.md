# 00. ゲーム概要

> ステータス: ドラフト v0.2 / 最終更新: 2026-09-22

## コンセプト

- **タイトル**: **THE CHAOS Ⅱ**(表記はこの通り。ローマ数字「Ⅱ」は U+2161)。コード上の識別子・リポジトリ名は `CardGame` のまま

- **ジャンル**: 1v1 のデジタルカードゲーム(シャドウバース / ハースストーン型)
- **世界観**: **ダークファンタジー**。写実寄りの絵柄、彩度を抑えた重い色調、陰影の強い光。カードの枠(金線と金属)とフィールド(酒場のテーブル)の質感に合わせる。
  イラストは現在の 122 枚(`Tools/ArtGen` の pollinations 生成、写実寄り・暗めの色調)を基準にし、追加・作り直しは同じプロンプト文言で行う。【要確認】固有名(世界の名前、クラス名)は後で決める
- **プレイ形態**:
  - AI 対戦(ソロ)
  - オンライン対戦(友人と部屋コードで接続)
  - ローカル対戦(1 台を交互に操作。開発・デバッグ用の位置づけ)
- **プラットフォーム**: Android を先行、後に iOS
- **規模**: 友人に配布して遊んでもらう。ストア公開・課金・アカウント管理はしない

## 設計上の優先順位

1. ルールが正しく動くこと(Core のテストで担保)
2. 実機で触れること(素朴な UI でよい)
3. オンラインで友人と遊べること
4. カードの量とオリジナリティ
5. 演出・ビジュアル

## やらないこと(明示的に除外)

- ランクマッチ、レーティング、マッチメイキング
- カードパック、ガチャ、所持管理(全カード最初から解放)
- アカウント、ログイン、サーバー側のデータ保存
- 自前サーバーの運用(Unity Relay を使いサーバーレスで実現)
- 観戦、リプレイ共有(将来の検討事項)
