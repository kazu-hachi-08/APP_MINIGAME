# playtest 2026-09-22: 第 1 回バランス調整

計測: `dotnet run -c Release --project Core/CardGame.Cli -- selfplay --games 300 --seed {11,31,47}`
(1 組み合わせ 300 戦 × 15 組 × 3 シード = 13,500 戦。先攻は 1 戦ごとに交代)

## 結果(クラス別 総合勝率、ミラー除く)

| クラス | 調整前 | 調整後 |
|---|---|---|
| 森の民 | 59.4% | **50.1%** |
| 竜族 | 55.4% | **52.4%** |
| 騎士 | 53.0% | **50.6%** |
| 魔導 | 45.6% | **47.8%** |
| 死霊術師 | 36.6% | **49.2%** |
| **幅** | **22.8 pt** | **4.6 pt** |

仕様(03-cards.md)の目標「40〜60% に収まる」を全クラスで満たし、実質 47〜53% に収束した。

## 調整内容と理由

### 死霊術師(弱すぎ: 36.6%)
素のスタッツが低いうえ、自傷カードが 20 HP のゲームで割に合っていなかった。

| カード | 変更 | 理由 |
|---|---|---|
| U002 腐肉喰らい | 1/3 → **2/3** | 2 コストとして盤面に触れなさすぎた |
| U004 死霊の蝙蝠 | 3 コスト → **2 コスト** | 2/2 ドレインは 3 コスト相当のスタッツに届かない |
| U007 死神の使い | 3/2 → **3/3** | 必殺が仕事をする前に 1 回の除去で落ちていた |
| U009 屍術師 | 5 コスト → **4 コスト** | 供物(味方 1 体)というコストを既に払っている |
| U010 亡霊騎士 | 4/2 → **4/3** | 疾走後に生き残れず、ラストワードも含めて損 |
| U011 死者の王 | 7 コスト → **6 コスト** | 7 コストでは 7〜8 ラウンドの試合に間に合わない |
| U008 血の契約 | 自傷 2 → **自傷 1** | ドローのために自分の負け筋を太らせていた |
| U019 死の宣告 | 自傷 2 → **自傷 1** | 同上。除去としての採用価値を確保 |
| U017 爆裂する屍 | 全体 2 → **全体 3** | 味方 1 体を失う対価として弱く、横並べに間に合わなかった |

### 森の民(強すぎ: 59.4%)
PP 加速・回復・守護・スタッツを全部持っていた。**加速そのものは残し、付随する得を削る**方針。

| カード | 変更 | 理由 |
|---|---|---|
| D006 古木の精 | 2/6 → **2/5** | 4 コストの守護としては硬すぎ、序盤の弱さという設計上の弱点が消えていた |
| D008 大樹の守り手 | 4/6 + 回復 3 → **3/6 + 回復 2** | 守護・スタッツ・回復の 3 役を 5 コストで担っていた |
| D009 森の賢者 | 3/5 → **3/4** | 加速 + ドロー付きで素のスタッツまで基準以上だった |
| D020 豊穣の祭壇 | ドロー 2 → **ドロー 1** | 加速 + 2 ドローは 3 コストの置物として過剰 |

### 竜族(強すぎ: 55.4%)

| カード | 変更 | 理由 |
|---|---|---|
| G008 岩竜 | 3/7 → **3/6** | 5 コストの守護としては越えにくすぎた |
| G010 炎竜 | 6/6 → **5/6** | 全体 2 ダメージ + 大型の二枚看板が強すぎた |
| G015 竜の息吹 | 3 コスト → **4 コスト** | 横並べクラスに対して早すぎた(対騎士 62%) |
| G016 灼熱のブレス | 4 コスト → **5 コスト** | 単体 3 + 全体 1 は 4 コストの範囲を超えていた |

## AI の改善(計測の信頼性のため)

貪欲 AI の盤面評価を調整できるようにし(`Core/CardGame.Core/Ai/AiTuning.cs`)、次を変更した。

- 手札 1 枚の価値 0.6 → **1.0**(「味方を破壊してドロー」する類のカードを評価できるように)
- フォロワーに基礎値 +0.5、**ラストワード持ちは失う痛みを -1.0 割引**(死霊術師の設計を理解させる)
- **デッキ残枚数が 5 以下でペナルティ**(デッキ切れ = 敗北を認識する)

※ 手札の価値を 1.5〜2.0 まで上げると、AI が手札を抱えすぎて逆に死霊術師の勝率が下がった(掃引で確認)。1.0 が最良。

## 残る課題

- **先攻の勝率 55.9%**。先攻有利が残っている(後攻は初期手札 4 枚 + 先攻は初ターンのドローなし、という現行の補正では足りない)。
  対策案は「後攻に 1 回だけ使える PP+1」「後攻の初期手札を 5 枚に」「後攻は 2 ターン目から PP+1」など。**ルール変更なのでオーナーの判断待ち**
- 1 手先読みの貪欲 AI であることは変わらないため、コンボ寄りのカード(供物、バフ)の評価は依然として控えめ。オーナーの実プレイでの体感と突き合わせたい
- 採用されないカード(`G017 竜の財宝`, `D015 自然の恵み`, `U008 血の契約` など)は、プリセットデッキの構成を見直す段階で再検討する

## 追記: 先攻有利の補正(2026-09-22)

オーナーの判断で案 A(後攻に 1 試合 1 回の PP +1、名称「覚醒の刻」)を実装した。

- 無条件に発動させると効きすぎた(先攻 55.9% → **43.7%**。後攻が有利になってしまう)
- 「最大 PP が N 以上」の閾値を掃引: N=3 → 先攻 49.2% / **N=4 → 50.0%** / N=5 → 52.1% / N=6 → 54.2%
- **閾値 4(後攻の 4 ターン目以降)を採用**。18,000 戦(300 戦 × 15 組 × 4 シード)で先攻 50.0%

このときのクラス別勝率:

| クラス | 勝率 |
|---|---|
| 竜族 | 52.6% |
| 森の民 | 51.1% |
| 騎士 | 50.1% |
| 死霊術師 | 48.5% |
| 魔導 | 47.6% |

先攻・後攻ともほぼ 50%、クラス幅 5.0pt に収まった。フェーズ5 で進化システムを入れるときは、この追加 PP と合わせて再調整する。
