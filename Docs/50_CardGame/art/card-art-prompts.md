# カードイラスト生成用リスト

生成した画像は **縦長 2:3(例 832×1248)** で、`ファイル名` の通りに保存して `Unity/Assets/Resources/CardArt/` に置く。
手札では画像の **上 2/3** だけが見える(下 1/3 は効果テキストに隠れる)。場では全体が見える。主役は上半分〜中央に。
既に作成済み: N001。
PNG / JPG どちらでも可。共通の画風指定は各プロンプトの先頭に入っている。

生成コマンド: `dotnet run --project Core/CardGame.Cli -- art --out docs/art`
