# 枠 A(石と金属の装飾枠)とフィールド背景の生成用プロンプト

Gemini(Web)で生成する用。**背景は無地(できれば黒一色)**で出してもらえば、Claude 側で透過処理して Unity に組み込む。
取り込みは `Tools/ArtGen` のコマンドで行う(下記)。画像を置いただけでもインポート設定は自動で付く。

## フィールド背景(1 枚、16:9、できるだけ高解像度)

> 上から見下ろした、ファンタジー世界の酒場の重厚な木のテーブル。濃い色のオーク材で木目がはっきり見え、縁には彫刻と真鍮の金具。
> 画面の左右には蝋燭の暖かい光がわずかに差し込む。テーブルの上は何も置かれていない(カードもマットも無し)。
> 写実的なデジタルペインティング、暖色、落ち着いた暗めのトーン、文字・ロゴなし。横長 16:9。

画面中央(横 約 70%、縦 約 75%)は革のプレイマットで隠れるので、**見えるのは周辺部**。周辺に金具や蝋燭の光があると効果的。

取り込み: `dotnet run --project Tools/ArtGen -- table <画像のパス>`
→ `Unity/Assets/Resources/Field/table.jpg`(2048×1024 に中央切り抜き)。現在は pollinations で作った仮画像が入っている。

## カード枠 A(クラスごと 1 枚、縦長 7:10、中央は空)

共通の指示:
> トレーディングカードの装飾枠のデザイン。縦長 7:10。**中央は完全な黒(#000000)の空白**にして、枠だけを描く。
> 枠の太さはカード幅の 5〜7%。四隅に金属の飾り。飾りは枠の外側にはみ出さない。
> 写実的なファンタジー装飾、文字・ロゴなし、枠の外側(画像の余白)も黒。

注意点:
- 名前の巻物や数値の台座は**不要**(名前帯とバッジはゲーム側で描く。左上=コスト、左下=攻撃、右下=体力の丸バッジが枠の上に載る)
- 枠の中に黒い部分(黒鉄など)があっても、中央の黒と繋がっていなければ透過されない
- 枠の内縁は直線的に(内側の飾りが大きいとイラストや効果テキストに被る)

クラス別の素材指定(上の共通指示の後に付ける):

| ファイル名 | クラス | 素材の指示 |
|---|---|---|
| `frame_neutral.png` | ニュートラル | 古い石と鉄。灰色の石に鉄の鋲、飾りは控えめ |
| `frame_knight.png` | 騎士 | 磨かれた銀と青い宝石、金の紋章(王国の盾)、白と青のリボン |
| `frame_mage.png` | 魔導 | 紫水晶と黒曜石、光る魔法のルーン、金の細工 |
| `frame_necromancer.png` | 死霊術師 | 骨と黒鉄、絡みつく鎖、緑に光るひび割れ |
| `frame_druid.png` | 森の民 | 生きた蔦と樹皮、苔、小さな花、木の年輪 |
| `frame_dragon.png` | 竜族 | 赤黒い竜の鱗と溶岩のひび、金の爪の飾り |

取り込み: `dotnet run --project Tools/ArtGen -- frame <画像のパス> knight`(クラス名は neutral / knight / mage / necromancer / druid / dragon)
→ `Unity/Assets/Resources/Frames/frame_knight.png`(512×732、中央と外側の黒を透過)。
黒の判定しきい値は `--threshold 40`(0〜255)で調整できる。

ゲーム側の挙動:
- `Frames/frame_<class>` があればそのクラスのカードに重ねる(9-slice ではなく単純に引き伸ばし。カードは常にほぼ 7:10)
- クラス用が無く `frame_neutral` だけあれば全クラスにそれを使う。何も無ければ枠 B(金線)のまま
