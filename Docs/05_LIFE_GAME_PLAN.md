# 人生ゲーム 実装計画書（一時）

> 仕様書：[05_LIFE_GAME_SPEC.md](05_LIFE_GAME_SPEC.md)
> この計画書は実装中の進捗管理用。全フェーズ完了後、決まった内容を仕様書へ反映してから削除する。

## 方針

* **各フェーズの終わりで必ず遊べる状態にする**（Playable Build優先）
* ルール（`Scripts/Rules/`）を先に作り、EditModeテストで固めてから見た目を載せる。オンラインとNPCが同じ計算を通るので、後のフェーズで作り直しにならない
* 1フェーズ＝1ブランチ＝1PRを目安にする

## 実装中に決めたこと（フェーズ7で仕様書へ反映）

* 区間ごとのマスの表・固定マスの位置は `LifeBoardShape.CreateDefault()` のとおり（結婚は区間Bの11マス目、給料日は区間B・安全・ギャンブルに1つずつ、区間Cに2つ）
* 職業の給料：会社員180・警察官130・大工130・料理人160・保育士150・医者250・弁護士300・社長350（係の職業は給料を低めにした）
* 転職マスで引くのは一般職のみ（今の職業は除く）。上級職は大学ルートの卒業マスでしか就けない
* フリーターは分岐①でフリーターの道を選んだ時点でフリーターになる
* 係の手数料：払う本人が係なら、他に同じ係の人がいても銀行に払う
* 同じ番号の株を自分で2枚以上持ってもよい（NPCは持っていない番号だけ買う）
* 分岐マスにちょうど止まったときは何も起きず、次の手番の最初に道を選ぶ
* 盤面生成・出目・職業カード・精算の家の売却ルーレットは、すべて `LifeGameState.Random` の1本から引く。NPCの乱数は別にする（NPCの考える回数で出目がずれないように）
* 盤面の座標は `LifeBoardLayout`（`Data/LifeBoardLayout.asset`）。持つのはマス番号 → 座標だけで、道の形（区間・分岐・固定マス）は `LifeBoardShape` のままコードに置く（ルールは Unity に依存しない asmdef で、テストもこれを使うため）。マスの並びはシードで変わらないので番号で引ける
* つづら折り：横5列・間隔1.3。共通区間は5列で折り返し、分岐①の3ルートは1列ずつ、分岐②の2ルートは2列ずつ（間に1列空ける）。区間の間は1行空け、区間をまたぐ道は「上 → 横 → 上」の鉤形にして他のルートのマスの下を通らないようにした
* レイアウトはマス数が盤面と合わないときだけ作り直す。形を変えたら `Tools > MiniGame > LifeGame > Regenerate Board Layout`
* カメラの横は、盤面が画面に収まれば中央固定、縦長の端末で収まらないときだけはみ出さない範囲でコマを追う
* 1回の操作で起きたこと（移動中の給料・配当も含む）は、移動し終えてから1つのポップアップにまとめて出す。手番が変わる前に閉じるので、端末を渡す前に結果を読める
* 約束手形の返済は財布から1枚ずつ、ルーレットを回す前だけ（移動や選択の途中で状態が変わって表示とずれないように）
* テーマが持つのは表示名・通貨・職業名・家の名前・ルート名・マスの一言・色（背景・道・マスの色8グループ）。マスの名前（給料日・病気など）と保険の名前は3テーマ共通で `LifeTexts` に置く
* マスの一言は止まったときのイベント表示に「【出費】」の下の行に「スマホの画面を割った」のように出す。選び方は盤面生成で決めた `LifeCell.TextVariant` を文面の数で割った余り（盤面はテーマより先に作るため）
* テーマ選択はボタンを押したら即決定。選び直しはプレイヤー設定の「戻る」。選んだ時点で背景色を変える
* コマの形はテーマごと（現代＝車・ファンタジー＝馬車・宇宙＝宇宙船）
* マスの文字（TextMesh）はイベント表示の Text からフォントを借りる（ブラウザ版で WebFontApplier が日本語フォントに差し替えた後のものを使うため）
* 能力の値は `LifeRuleConfig`（初期所持金+100・給料+10%・支払い−10%）。割合は端数切り捨て
* しっかり者の減額は、出費・学費・病気・事故・火事（家なしの小額も含む）に効く。係へ払うときも減った額を払う。家・保険・株の購入とご祝儀には効かない
* 振り直しは `LifePending.Reroll` で出目を見せてから選ぶ。「このまま」を選んでも能力は残る。振り直すときはもう一度フリックする
* NPCの手形返済は、回す前にまとめて済ませる（人間と同じく回す前だけ）
* 勝敗：1位が人間なら勝利、NPCなら負けとして ResultDialog を出す。表示名は「P1 らっきー」（席番号＋キャラ名）。所持金バーは幅の都合で「P1」のまま
* NPCのイベント表示は0.8秒で自動で閉じるが、タップでも閉じられる
* キャラ選択は立ち絵・名前・能力の説明
* オンラインの試合前：モード選択（「1台で遊ぶ」／部屋を作る／参加）→ ホストはテーマ選択、参加者は「ホストがテーマを選んでいます」→ キャラ選択（自分の席だけ・「戻る」なし）→「他のプレイヤーを待っています」。待機表示はキャラ選択パネルのボタンを隠して文面だけ出す
* 相手の手番のコマンドはキューにためて届いた順に再生する（自分がイベント表示をタップするまで待っている間に次の人のコマンドが届いても取りこぼさないため）。手番以外・範囲外は再生時に `LifeRules.IsValid` で捨てる
* 相手の手番は「○○の番」・イベント表示とも0.8秒で自動で閉じる。自分の手番の結果はタップで閉じる
* フリックの強さは送らない（出目に影響しないため）。相手の回転演出は固定の強さ（`_remoteFlickStrength`）
* オンラインの表示名は自分の席だけ「P2 らっきー（あなた）」。所持金バーとイベント表示は P番号のまま
* 勝敗：オンラインは自分が1位のときだけ勝利
* `life.setup` はホストからのものだけ採用する（クライアントから届いても中継しない）
* 1台のとき、回した結果の表示が「次の手番がNPCかどうか」で自動で閉じていた不具合を直した（Apply で手番が移った後に判定していたため）
* ドット絵は `LifeGameArtGenerator`（`Tools > MiniGame > LifeGame > Regenerate Art`）で `Sprites/` に生成する。アイコンと乗り物は `LifeArtPatterns` の文字列（1文字＝1ピクセル）で持ち、顔・立ち絵・背景は手続きで描く。1単位＝16px
* マスと道は白地で描いてテーマの色を掛ける。マスはアイコン＋下に1行（金額が決まっていれば金額、なければ名前）
* 乗り物・背景タイルはテーマ（`LifeThemeData`）、顔・立ち絵はキャラ（`LifeCharacterData`）が参照を持つ。Scene生成時に空の欄だけ埋める（手描きに差し替えた参照を消さないため）
* 背景タイルは色を掛けずにテーマの背景色で直接描く（宇宙の星は背景より明るく、掛け算では出せないため）。盤面の外側20単位まで敷き詰める
* コマは上向き固定（進む向きに回さない）。車体を席の色に染め、窓・車輪・馬などは染めない別の絵を重ねる。運転席（右前）にキャラの顔、助手席に結婚相手、後部座席に子供を2人まで（計4人）
* お金の増減・給料日・結婚・出産・ゴール・保険・手形は、コマの上に文字を浮かべて音を鳴らす（止まらずに進める。続けて出るときは0.35秒ずつ空ける）。係やご祝儀で受け取った人のコマにも「+」を出す
* 所持金バーは0.6秒かけて数え、増えたら緑・減ったら赤で表示する
* 精算は席順に1人ずつ。精算前の所持金は内訳から逆算して見せ、家を持っていれば画面下のルーレットをルールの出目で止めてから1行ずつ足す。読み終えたらタップで次の人へ。全員終わったら順位発表（イベント表示）→ 勝利演出 → ResultDialog
* 勝利演出はモルックと同じ形（共通化はせず人生ゲーム側に `VictoryShowView` を置く）。立ち絵はバンザイの2頭身
* SE（`LifeAudio`）：ルーレットは区画の境目を越えるたびにカチカチ、止まったら「ピンポン」。移動・お金の増減・給料日・結婚/出産（鐘）・ゴール・勝利
* ルーレットの盤は PNG にせず実行時に描く（縁と中心の軸を足した）
