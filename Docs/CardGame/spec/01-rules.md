# 01. 対戦ルール

> ステータス: v1.0(フェーズ2 実装基準)/ 最終更新: 2026-09-21
> 初期実装(フェーズ2)の対象は「基本ルール」節まで。「フェーズ5で追加」節は将来用。

## 基本パラメータ

| 項目 | 値 | 備考 |
|---|---|---|
| プレイヤー数 | 2 | |
| リーダー初期 HP | 20 | 上限も 20(回復で超えない) |
| デッキ枚数 | 40 枚ちょうど | 同名カードは 3 枚まで。ドラフトのデッキ(カオス)は 30 枚・クラス縛りなし(07-draft.md) |
| 初期手札 | 先攻 3 枚 / 後攻 4 枚 | |
| 後攻の追加 PP | 1 試合に 1 回、自分のターン開始時に PP +1 | 「覚醒の刻」。先攻有利(自己対戦で 55.9%)の補正。進化導入時(フェーズ5)に再調整 |
| 手札上限 | 9 枚 | 超過分は引いた時点で消滅(墓場へ) |
| 場の上限 | 5 | フォロワー + アミュレットの合計 |
| PP 上限 | 10 | |
| 先攻/後攻 | ランダム | |

## ゲームの流れ

```
[マリガン] → [先攻 T1] → [後攻 T1] → [先攻 T2] → ... → 決着
```

### マリガン

1. 両者が初期手札を引く(先攻 3 / 後攻 4)
2. 各プレイヤーは手札のうち任意の枚数を選び、同じ枚数を引き直す(1 回のみ)。戻したカードは引き直した後にデッキへ混ぜる(戻したカードをすぐ引き直すことはない)
3. 戻したカードを混ぜたデッキをシャッフル

### ターン構造

各ターンは 3 つのフェーズからなる。

**1. 開始フェーズ**
1. 最大 PP を +1(上限 10)。PP を最大まで回復
2. カードを 1 枚ドロー(デッキが 0 枚なら → 敗北、後述)
3. アミュレットのカウントダウンを 1 減らす(0 になったら破壊)
4. 「ターン開始時」トリガーを解決

**2. メインフェーズ**
プレイヤーは以下を任意の順序・回数で行える。
- 手札のカードをプレイ(コスト分の PP を消費)
- フォロワーで攻撃
- ターン終了を宣言

**3. 終了フェーズ**
1. 「ターン終了時」トリガーを解決
2. 相手のターンへ

### 後攻の追加 PP(覚醒の刻)
- 後攻プレイヤーは **1 試合に 1 回だけ**、自分のターンの開始フェーズで PP を +1 される(最大 PP は増えない。そのターンだけ使える追加の 1 PP)
- 使用するタイミングは **自動**。「最大 PP が 4 以上」かつ「+1 すれば手札のカードを 1 枚多くプレイできる」最初のターンに発動する(序盤に出ると効きすぎるため閾値を設けた)
- 使い切ると以降は発動しない。画面には「覚醒の刻」としてログに出す
- 実装: `PlayerState.BonusPpLeft`(初期値: 先攻 0 / 後攻 1)、閾値は `GameRules.SecondPlayerBonusPpFromMaxPp`(4)。ターン開始フェーズの PP 回復後に判定し、`BonusPpUsedEvent` を出す
- 計測: 導入前は先攻 55.9%、閾値 4 で **先攻 50.0%**(18,000 戦)。閾値 3 では 49.2%、5 では 52.1% だった

### 第 1 ターンの特例
- 先攻の第 1 ターンはドローしない(初期手札 3 枚のまま)。
- 後攻はドローする(4 → 5 枚)。

## カードのプレイ

- コスト ≤ 現在 PP のときのみプレイ可能。プレイ後、コスト分 PP を減らす
- **フォロワー**: 場に出す。場が 5 体なら出せない。「ファンファーレ」を解決
- **スペル**: 効果を解決し、墓場へ。対象を選ぶスペルは、正当な対象が存在しないときプレイ不可
- **アミュレット**: 場に出す(場の上限を消費)。「ファンファーレ」を解決

## 戦闘

### 攻撃の宣言
- 攻撃できるのは自分のフォロワーのみ。1 ターンに **1 体につき 1 回**
- **このターンに場に出たフォロワーは攻撃できない**(召喚酔い)。例外は「疾走」「突進」
- 攻撃対象: 相手リーダー、または相手フォロワー

### 守護
相手の場に「守護」を持つフォロワーがいる間、攻撃対象は守護フォロワーに限られる。

### ダメージ処理
- フォロワー → フォロワー: **同時に**互いの攻撃力分のダメージを与える
- フォロワー → リーダー: 攻撃側のみダメージを与える(反撃なし)
- 体力が 0 以下になったフォロワーは破壊され墓場へ。「ラストワード」を解決
- フォロワーのダメージは **ターンをまたいでも回復しない**(体力は減ったまま)
- 攻撃力 0 のフォロワーは攻撃できない
- 攻撃対象になるのはリーダーとフォロワーのみ。アミュレットは攻撃できず、守護の判定にも含まれない

### 破壊と同時処理
- 複数のフォロワーが同時に破壊された場合、ラストワードは **手番プレイヤーの場 → 相手の場**の順、それぞれ**左から順**(場に出た順)に解決する
- 効果解決中に新たにトリガーが発生した場合、現在の解決が終わってから順に処理する(キュー方式、割り込みなし)

## 勝敗

以下のいずれかで即座に決着する。
- 相手リーダーの HP が 0 以下 → **勝利**
- 自分がデッキ 0 枚の状態でドローしようとした → **敗北**(シャドウバース式。累積ダメージ方式は採用しない)
- 両者の HP が同時に 0 以下 → **引き分け**
- 降参 → 降参したプレイヤーの敗北
- (オンライン)相手が切断し、再接続猶予を過ぎた → 相手の敗北

## 用語の定義

- **破壊**: 場から墓場に移動すること。体力 0 による破壊と、効果による破壊は同じ扱い(どちらもラストワードが発動)
- **消滅**: 墓場を経由せず取り除かれること。ラストワードは発動しない(初期セットでは使用しない)
- **ダメージ**: 体力を減らすこと。「ダメージを与える」効果と「破壊する」効果は区別する(必殺・ドレインはダメージにのみ反応)
- **バフ**: 攻撃力/体力の永続的な増減。体力 +N は現在体力と最大体力の両方を +N

## フェーズ5で追加(初期実装には含めない)

### 進化(Evolve)
- 進化ポイント(EP): 先攻 2 / 後攻 3。先攻は 5 ターン目、後攻は 4 ターン目から使用可能
- 1 ターンに 1 回、EP を 1 消費して自分のフォロワー 1 体を進化させる
- 進化したフォロワーは +2/+2 され、**そのターンに出た場合でもフォロワーに攻撃できる**(リーダーは不可)
- 「進化時」トリガーを解決
- 後攻の手札・追加 PP・EP 補正はこの節と合わせて再調整する

### ターン制限時間(オンライン)
- 1 ターン 90 秒。超過で自動ターン終了。05-online.md 参照
