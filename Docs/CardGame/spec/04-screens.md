# 04. 画面仕様

> ステータス: ドラフト v0.3 / 最終更新: 2026-09-22
> フェーズ3では「動くこと」優先。装飾はフェーズ5。

## 画面フロー

```
[タイトル / メインメニュー]
   ├→ [AI 対戦]      → [デッキ選択(自分 + 相手)] → [バトル] → [リザルト] → メインメニュー
   │                    └ 「ドラフトで作る」→ [ドラフト] → [デッキ確認] → [バトル](相手 AI も自動ドラフト)
   ├→ [ローカル対戦]  → [デッキ選択(1P + 2P)]    → [バトル] → [リザルト]
   ├→ [AI 観戦]      → [デッキ選択(両方)]        → [バトル]
   ├→ [オンライン対戦] → [デッキ選択(自分)]        → [部屋作成 / 部屋参加] → [バトル] → [リザルト]
   │                    └ 「ドラフトで作る」→ [部屋作成 / 部屋参加] → [2 人同時にドラフト] → [デッキ確認(相手待ち)] → [バトル]
   ├→ [カード一覧]
   ├→ [デッキ編集](保留)
   └→ [設定](未定)
```

画面向き: **横持ち(Landscape)固定**。手札(最大 9 枚)を重ねずに並べられ、タップ精度と盤面の見通しを優先する(ハースストーン方式)。両手持ち前提。
縦方向の高さが限られるため、カードの詳細は長押し拡大で補う。

## タイトル / メインメニュー
- 机の背景の上に、タイトル「THE CHAOS Ⅱ」を金文字(暗い縁取り + 影)で大きく置く。下に小さく版数
- 中央に羊皮紙のボタンを縦に並べる: AI 対戦 / ローカル対戦 / オンライン対戦 / AI 同士を観戦 / カード一覧 / 設定(ボタンに補足の括弧書きは付けない。オーナー判断 2026-09-23)
- 右下に全画面ボタン(ブラウザ・PC 用)。デッキ選択はこの画面では行わない(モードを選んでから)

## 設定
- メインメニューの「設定」、または対戦中の「降参 / メニュー → 設定」から開く(中身は `SettingsPanel` で共用)
- BGM の音量 / 効果音の音量(スライダー、0〜100%。PlayerPrefs に保存)、全画面の切り替え、「音を試す」ボタン

## デッキ選択
- モードごとに必要なデッキだけを選ぶ: AI 対戦 = 自分 + 相手(AI)、ローカル = 1P + 2P、観戦 = 両方、オンライン = 自分のみ
- デッキは横一列の羊皮紙カード(代表イラスト + デッキ名 + クラス)。タップで選択、金の縁で選択中を示す
- 「← 戻る」でメニューへ、「対戦開始」(オンラインは「部屋へ」)で次へ。既定は 1 番目(相手は 2 番目)
- AI 対戦・オンライン対戦では、自分のデッキの列の先頭に「ドラフトで作る」(カオスの紋章)を置く。選んで次へ進むとドラフト画面へ(07-draft.md)

## ドラフト(07-draft.md)
- **ドラフト画面**: 上に「ドラフト N / 10」と制限時間(30 秒)のバー。中央に 3 組を横に並べ、各組は羊皮紙の台に 3 枚のカード(中サイズ)と「この組を取る」ボタン。
  カードを押すと詳細(取らない)。下に取ったカードのコスト分布(低・中・高・大型の棒)と「9 / 30」。残り 5 秒でバーが赤くなり、時間切れでランダムに 1 組を取る
- **デッキ確認画面**: 30 枚をコスト順に小サイズで並べる。右下「対戦開始」(オンラインは「部屋へ進む」)、左下「作り直す」「← 戻る」(デッキ選択へ)

## バトル画面(最重要)

横画面のレイアウト(基準 1920×1080):

```
┌──────────┬──────────────────────────────┬──────────┐
│ 相手リーダー │ 相手の場(最大 5、横並び)            │ 相手 手札枚数 │
│ HP / PP    │                              │ デッキ枚数   │
│            ├──────────────────────────────┤            │
│ 自分リーダー │ 自分の場(最大 5、横並び)            │ 自分 デッキ枚数│
│ HP / PP    │                              │ [ターン終了]  │
├──────────┴──────────────────────────────┴──────────┤
│ 自分の手札(横一列、最大 9 枚、重ねない)                    │
└────────────────────────────────────────────────────┘
```

- 左列: 両リーダー。攻撃・回復・スペルのドロップ先になる
- 中央: 盤面 2 段。フォロワーは縦長の小カード(約 150×200px)で、名前・攻撃力・体力・キーワードアイコンのみ表示
- 右列: 枚数表示とターン終了ボタン(右手親指の位置)
- 下段: 手札。9 枚でも 1 枚あたり約 200px 幅を確保できる。効果テキストは省略し、タップで拡大
- 相手の手札は枚数のみ表示(裏面を並べる演出はフェーズ5)

### 操作
| 操作 | 動作 |
|---|---|
| 手札をタップ | カード拡大表示(効果テキストを読む) |
| 手札を場へドラッグ | プレイ。対象選択が必要なら続けて対象をタップ |
| 自分フォロワーを相手へドラッグ | 攻撃。ドロップ先がリーダーかフォロワー |
| 場のフォロワー/アミュレットをタップ | 拡大表示(横画面では盤面カードが小さいため必須) |
| カードにホバー(PC)/長押し(スマホ) | そのカードが持つキーワード・トリガーの説明をツールチップ表示 |
| ターン終了ボタン | 終了フェーズへ |
| 右上メニュー | 降参 / 設定 |

### 表示上の必須情報
- プレイ可能なカードは手札で光らせる(PP 足りる & 場に空きがある & 対象がいる)
- 攻撃可能なフォロワーを光らせる
- 守護は盾アイコン、その他キーワードもアイコン
- 拡大表示にはキーワード・トリガー(ファンファーレ / ラストワード / カウントダウン)の説明文を併記する
- エフェクト(フェーズ5 で強化、2026-09-23): 実装は `Assets/Scripts/UI/Fx.cs`。画像素材を使わず実行時生成のスプライトを uGUI で動かす(WebGL / スマホでも軽い)
  | 場面 | 演出 |
  |---|---|
  | 攻撃 | 攻撃側が対象へ突進 → 命中で交差する斬撃 + 衝撃波の輪 + 白い芯。リーダーへの攻撃は画面が揺れる |
  | 効果ダメージ | 対象に小さな衝撃 + 赤の点滅 + 数値ポップ。3 以上でリーダーに入ると画面が揺れる |
  | 対象を取るカード | 発生源(手札の位置)から対象へクラス色の光弾が飛ぶ |
  | 召喚 | ポップイン + 足元の光柱と床の輪(クラス色) |
  | 強化 | 金の輪が下から上へ抜ける + カードが脈動 |
  | 破壊 | 暗い煙 + 破片が飛び散ってフェードアウト |
  | 回復 | 緑の光の粒が昇る + 数値ポップ |
  | ターン開始 | 中央にバナー |
  再生中は操作不可。`-preview-fx` で各エフェクトの確認用スクリーンショットを撮れる
- 相手のターン中は操作不可のオーバーレイ
- ログ(直近の行動を数行)をトグル表示できると検証が楽

## リザルト
- 勝敗、ターン数、与えたダメージ合計 程度。「もう一度」「メニューへ」

## カード一覧(図鑑)
目的: 対戦の前後に「どんなカードがあるか」を眺める。デッキ編集の部品(一覧グリッド・絞り込みバー・拡大表示)を共用する前提で作る。

- 入口: メインメニューの「カード一覧」ボタン。「← 戻る」でメニューへ
- 上部 2 段の絞り込みバー(複数同時に効く。件数を表示)
  - クラス: 全部 / 中立 / パラディン / メイジ / ネクロマンサー / ドルイド / ドラゴンナイト(ボタンで切り替え。案 (a))
  - 種類: 全 / フォロワー / スペル / アミュレット
  - コスト: 全 / 1 / 2 / … / 6 / 7+
  - 並び: コスト順(同コストは ID 順)/ 名前順
- 一覧: **1 行 6 枚**、縦スクロール(スマホはフリック、PC はホイール。ホイール 1 ノッチ ≒ 半行、フリックは長めに滑る)。カードはバトル画面と同じ `CardView`(拡大サイズを縮小して表示)
  - 全部のときの並びは 中立 → 騎士 → 魔導 → 死霊術師 → 森の民 → 竜族 の順
  - トークン(`isToken`)は表示しない
- タップで拡大表示 + キーワード説明(バトル画面と同じ部品)。タップで閉じる
- 開発用: 右上の「ID」トグルで各カードの ID と、絞り込み結果の内訳(種類別枚数・平均コスト)を表示する

## デッキ編集
- クラス選択 → カード一覧(コスト順、フィルタ: コスト/種類)→ タップで追加、デッキ側タップで削除
- 40 枚ちょうどでのみ保存可。同名 3 枚制限
- 保存先: 端末ローカル(`Application.persistentDataPath` に JSON)

## オンライン用画面
- 部屋作成: 6 文字の部屋コードを表示、相手待ち。「招待リンクを送る」「コードをコピー」
- 部屋参加: コード入力 + 「貼り付け」(招待文やリンクからコードを取り出してそのまま参加)
- 招待リンクで開いた場合は、デッキ選択(ドラフトの部屋なら部屋の画面)へ直行して自動で参加する
- 詳細は 05-online.md

## 技術メモ(Unity)
- UI は **uGUI**(Canvas + RectTransform)。ドラッグ操作・レイアウトの実装例が豊富なため
- 解像度基準: 1920×1080(横)、Canvas Scaler で追従。ノッチ・パンチホールは Safe Area で回避
- カードは **イラスト全面表示**(ハースストーン方式)。上に名前帯+コスト、下に攻撃/体力バッジ。手札と拡大表示には半透明の効果テキスト帯、場はキーワードのみ。イラストが無いカードはクラス色。イラストは `Resources/CardArt/<ID>`(縦長 2:3 推奨)

## 書体とバッジ(オーナー決定 2026-09-22)
- 日本語: **Noto Serif JP Bold**(明朝。`Resources/Fonts/NotoSerifJP-Bold.otf`、OFL)。太字版のみ同梱するので `FontStyle.Bold` は合成しない
- バッジの数字: **Cinzel Bold**(ローマ碑文体。`Resources/Fonts/Cinzel-Bold.ttf`)
- コスト / 攻撃 / 体力のバッジ: 画像生成した「透かし彫りの金環」(`Resources/Badges/badge_rim.png`、中央は透明)の下に、
  手続き生成のカボション宝石(攻撃=赤 / 体力=緑 / コスト=水色)を敷き、数字を載せる。リム画像が無ければ金属リングにフォールバック。
  差し替えは `dotnet run --project Tools/ArtGen -- badge <画像> --hole 0.62 --name badge_rim`
- カードの質感(段階 1、2026-09-22): イラストの内縁に落ち影(額縁風)、名前帯は暗い鋼 + 上下の金線 + 金文字、効果欄は羊皮紙 + インク色の文字(種類ラベルは暗い赤)。
  段階 2 で名前帯・効果欄を Gemini 製の銘板 / 羊皮紙画像に、枠を枠 A に置き換える(`docs/art/gemini-requests.md`)
- カードの質感(段階 2、2026-09-22): 枠はクラス別の装飾枠画像(`Resources/Frames/frame_<class>`)、名前帯は鋼の銘板(`Plates/plate_name`)、効果欄は羊皮紙(`Plates/plate_text`)。
  枠画像は Tools/ArtGen が「開口部を一定の位置(横 8.5〜91.5%、縦 7〜93%)に揃える」ように正規化するので、CardView は固定の余白で中身を置く。
  場のカードにはキーワードのアイコン(`Keywords/kw_<keyword>`)を右上に縦並び。デッキ選択とカード一覧のクラス絞り込みにクラス紋章(`Emblems/emblem_<class>`)。
  素材はすべてローカル ComfyUI で生成(`dotnet run --project Tools/ArtGen -- assets`、定義は Tools/ArtGen/assets.json)

## カードの見た目: ハースストーン風(オーナー決定 2026-09-23)
- 写実寄りからハースストーン風へ切り替え。比率は実物のミニオンのカードを測った値(`CardView.Hs`)。起動引数 `-card-style real` で従来の見た目
- カードの縦横比は約 0.77(手札 230×300、拡大 552×720)。台紙はカードの横 74% × 縦 80%、楕円の絵は台紙の上端からはみ出す
- 楕円の額の外周は横 50% × 縦 45%(実物と同じ大きさ)。スペル・アミュレットは角丸の四角の額
- 名前は羊皮紙の巻物のリボン(書体は解星 徳明 ExtraBold、濃い茶の墨の色で黒い縁取りなし。オーナー決定 2026-09-23)、文章は明るい羊皮紙の欄。宝石はコスト = 左上の青い結晶、攻撃 = 左下の赤、体力 = 右下の緑(色はオーナー指定のまま)
- 場のフォロワーは楕円の肖像 + 攻撃・体力の宝石だけ。強調(攻撃できる等)は額の外側の楕円の光
- リーダー: クラスごとの肖像(`Resources/Leaders/leader_<class>`、カオス・中立を含む 7 種)を左の欄に太い金の楕円の額で表示し、体力は緑の宝石
- 素材はすべてローカル生成(`Tools/ArtGen/assets.json` の HsParts / Leaders、モデルは DreamShaper XL Turbo)
- 数値は必ず宝石の中に収める(宝石の内側 6 割の枠で自動縮小)。攻撃は「丸いルビー + 金の縁」(コスト = 六角の結晶、体力 = しずく形と形でも区別)
- 強調表示(プレイできる・攻撃できる・選択中など)は、カードの輪郭に沿った柔らかい光(加算合成)。手札は台紙の外周、場は楕円の額の外周に沿わせ、はみ出しは最小限にする
- ターン終了: 自分の手番で、ターン終了以外にできることが無くなったら(PP 切れ・出せるカードも攻撃できるフォロワーも無い)、ボタンが金色に脈打って知らせる
- リーダーの PP: 肖像の下に結晶を 10 個並べる(使える = 青く光る / 使った = 暗い / まだ無い = ほぼ透明)。覚醒の刻で上限を超えた分は金色。数値は出さない(オーナー判断)
