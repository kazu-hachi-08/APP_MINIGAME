# Gemini に依頼する素材リスト(2026-09-22 版)

Gemini(Web)で画像を作ってもらい、ファイルを Claude に渡すと取り込み処理まで行う。
共通の注意:
- **背景は真っ黒(#000000)**で「素材だけ」を描いてもらう(透過処理は Claude 側で行う)
- 文字・ロゴ・透かしは描かない
- できるだけ高解像度(長辺 1024px 以上)。PNG 推奨
- 1 回で気に入らなければ「同じ構図で、もっと〜」と続けて調整してよい

優先度: ★★★ = 見た目が大きく変わる / ★★ = あると良い / ★ = 余裕があれば

---

## A. 最優先(取り込み処理が実装済み)

### A1. ★★★ 机の背景 `table.jpg`(1 枚、横長 16:9)
> 上から見下ろした、ファンタジー世界の酒場の重厚な木のテーブル。濃い色のオーク材で木目がはっきり見え、縁には彫刻と真鍮の金具。
> 画面の左右には蝋燭の暖かい光がわずかに差し込む。テーブルの上は何も置かれていない(カードもマットも無し)。
> 写実的なデジタルペインティング、暖色、落ち着いた暗めのトーン、文字・ロゴなし。横長 16:9。

画面中央(横 70%・縦 75%)は革のプレイマットで隠れるので、**周辺部が見える**。
取り込み: `dotnet run --project Tools/ArtGen -- table <画像>`

### A2. ★★★ カード枠 A `frame_<class>.png`(6 枚、縦長 7:10)
共通:
> トレーディングカードの装飾枠のデザイン。縦長 7:10。**中央は完全な黒(#000000)の空白**にして、枠だけを描く。
> 枠の太さはカード幅の 5〜7%。四隅に金属の飾り。飾りは枠の外側にはみ出さない。内縁は直線的に。
> 写実的なファンタジー装飾、文字・ロゴなし、枠の外側(画像の余白)も黒。

| ファイル名 | クラス | 素材 |
|---|---|---|

| `frame_knight.png` | 騎士 | 磨かれた銀と青い宝石、金の紋章(王国の盾)、白と青のリボン |
| `frame_mage.png` | 魔導 | 紫水晶と黒曜石、光る魔法のルーン、金の細工 |
| `frame_necromancer.png` | 死霊術師 | 骨と黒鉄、絡みつく鎖、緑に光るひび割れ |
| `frame_druid.png` | 森の民 | 生きた蔦と樹皮、苔、小さな花、木の年輪 |

まず騎士 1 枚で試すのがおすすめ。取り込み: `dotnet run --project Tools/ArtGen -- frame <画像> knight`

### A3. ★★ バッジの金環 `badge_rim.png`(1 枚、正方形)
現在は無料生成のものを使用中。より精密なものに差し替えたい。
> 円形のメダルの縁だけを描く。バロック様式の金の透かし彫り、細かな唐草と小さな宝石の象嵌。
> **中央(直径の 60%)は完全な黒**で空ける。真上から見た構図、左右対称、写実的、黒背景、正方形、文字なし。

取り込み: `dotnet run --project Tools/ArtGen -- badge <画像> --hole 0.62 --name badge_rim`

## C. 画面・演出用

### C1. ★★ タイトルロゴ `logo.png`(1 枚、横長)
今は金文字のフォントだけ。
> 「THE CHAOS Ⅱ」のゲームロゴ。金属の立体文字に傷と光沢、「Ⅱ」はローマ数字。背景は黒、横長、他の文字なし。

### C2. ★★ キーワードのアイコン `kw_<keyword>.png`(5 枚、正方形)
守護 / 疾走 / 突進 / 必殺 / ドレイン。場のカードとツールチップに使う(今は守護の盾のみ手続き生成)。
> 小さな円形の金属アイコン。(守護) 盾 /(疾走) 翼のある靴 /(突進) 突き出した槍 /(必殺) 髑髏と短剣 /(ドレイン) 血の雫と牙。
> 金と黒鉄、写実的、黒背景、正方形、文字なし。

### C3. ★ 蝋封のターン終了ボタン `seal.png`(1 枚、正方形)
> 赤い蝋の封印。中央に王冠の押し型。真上から、黒背景、正方形。

### C4. ★ アプリのアイコン `icon.png`(1 枚、正方形 1024)
ホーム画面に追加したときの見た目(今は無し)。C1 のロゴを正方形に収めたものでよい。

### C5. ★ 主要カードのイラスト高品質化(任意)
全 122 枚は多いので、**各クラスの看板カード 1〜2 枚**(7 コスト前後のフォロワー)だけ Gemini で描き直す案。
プロンプトは `docs/art/card-art-prompts.md` に全カード分あり(ID で検索)。2:3 縦長、主役は上半分に。
渡された画像は `Unity/Assets/Resources/CardArt/<ID>.jpg` として同じ処理で取り込む。

## 渡し方
- ファイル名を上記に合わせて、まとめて送ってもらえれば順に取り込む(数枚ずつでも可)
- 画像を見て「もう少し明るく」など調整が要る場合は、Claude 側で明度・彩度の補正もできる
