# ADR-0002: オンライン対戦は Unity Relay + ホスト権威の決定論ロックステップで実現する

日付: 2026-09-21 / ステータス: 採択(実装はフェーズ4)

## 背景
自前サーバーの運用コスト・手間をかけたくない。対戦相手は友人のみで、チート対策は不要。

## 選択肢
1. 専用サーバー(自前ホスティング)— 隠し情報を厳密に守れるが運用が必要
2. Relay + ホスト権威 + サーバーがイベントを配信(隠し情報を守る)— 実装量が多い
3. **Relay + 決定論ロックステップ(両端末が全状態を持つ)** — 最も単純

## 決定
選択肢 3。両端末が同じ Core・同じシード・同じコマンド列を持つ。
ホストがコマンドの検証と採番だけを行う。

## 結果
- 良: 実装が最小。AI・ローカル対戦・リプレイと完全に同じ Core パスを通る
- 悪: 相手の手札やデッキ順がメモリ上に存在する(改造クライアントで覗ける)。友人間なので許容
- 制約: Core は完全に決定論的でなければならない(ADR-0001 と整合)
