# Phase 9: 残り40体の見た目パーツ

## ゴール

50体すべてが仕様 §5.5「見た目」列の通りに描かれ、見分けられる。

## 読むもの

* 仕様書: §5.5 キャラ一覧の「見た目」列、§7.2
* Phase 6 と Phase 8 の引き継ぎメモ（パーツID一覧・定義表の場所）
* `Editor/Art/PenguinPartPatterns.cs`、`Editor/Art/PenguinBodyPatterns.cs`、`Editor/UnitDefinitions.cs`

## 作るもの

* 足りない体の形・頭・手・背中・乗り物パーツを `PenguinBodyPatterns` / `PenguinPartPatterns` に追加
* `UnitDefinitions` の各キャラの `Look` を埋める

### 作業の分け方（1セッションで終わらなければここで区切る）

| 区切り | 対象 | 主な新パーツ |
| --- | --- | --- |
| 9-A | 壁・アタッカー（No 3,5〜10,12,14〜18,20〜22） | 雪玉 / 段ボール / 布団 / かまくら / 魚の剣 / グローブ / まわし / 長い足 / ハンマー / 黒ずきん / 刀・ちょんまげ / ドリル / 剣と盾 / 太い腕 |
| 9-B | 遠距離・妨害（No 24,25,27〜33,35〜42） | 釣り竿 / 大砲 / とんがり帽子・杖 / 長い銃 / ブーメラン / ロケット / 3段重ね / 雪のオーラ / 扇風機 / ナイトキャップ / 雪どけ水 / ハリセン / マイク・リボン / タコ足 / 風船 / 王冠・マント |
| 9-C | 大型（No 44〜50） | メカ / 戦車 / 氷山 / クジラ / 王冠・マント（大）/ 虹色 / 後光・羽 |

区切った場合は引き継ぎメモに「どこまで終わったか」を書き、INDEX の状態は **進行中** のままにする。

## 実装メモ

* 小さい（32×32）ので「シルエットで分かる」ことを優先。細かい模様は描かない
* 大型・乗り物系はパーツが体からはみ出してよい（キャンバスを広げるか拡大率で対応）
* 色だけで区別しているキャラ（虹色など）は、敵の赤パレットでも見分けられるか確認

## やらないこと

ゲームルール・数値の変更。

## 完了条件

* [ ] 50体すべてにパーツが付き、仮見た目のキャラが残っていない
* [ ] 敵味方どちらの色でも崩れない
* [ ] ボタンアイコンでも何のキャラか分かる

## ユーザー確認手順

1. アート生成 → `Sprites/` フォルダを一覧表示して50体を目視
2. 気になるキャラを伝える
