# 竜の卵の作り直し(2026-09-23)

計測: `dotnet run -c Release --project Core/CardGame.Cli -- selfplay --games 300 --seed {11,31,47} --card G001,G013`
(プリセット総当たり 4,500 戦 × 3。勝率は同型戦を除いた各デッキの通算)

## 問題
竜の卵(1 コスト 0/3、ラストワード: 子竜 2/2)は攻撃力 0 で自分から攻撃できず、相手に放置されると孵らない。
オーナー指摘「ラストワードが生かせない」。

## 検討した案

| 案 | 竜族 | 備考 |
|---|---|---|
| 現状(基準) | 52.3% | |
| 守護 1 コスト 0/3 | 73.7% | 増やす PP を貯める間、リーダーを守れるので竜族と噛み合いすぎる |
| 守護 1 コスト 0/2 | 72.3% | |
| 守護 2 コスト 0/2 | 68.0% | |
| 守護 2 コスト 0/4 | 72.0% | コスト・体力では収まらない → 不採用 |
| ターン開始時に孵る 1 コスト 0/3 | 62.8% | 体力を 0/1 にしても 61.7%。強さの源は「確実に孵る」こと |
| 同 2 コスト 0/3 | 57.8% | |
| 同 2 コスト + 卵の守り手 1/2 | 55.4% | |
| **同 2 コスト + 卵の守り手 1/2 + 竜人の長 2/3** | **54.6%** | **採用**。他 4 クラスは 47.9〜49.6% |

プリセットの卵を 3 → 2 枚にしても変化は小さかった(55.9%)。

## 採用した変更(03-cards.md v1.3)
- G001 竜の卵: 1 → **2 コスト**。「**自分のターン開始時、このフォロワーを破壊する**」を追加(新トリガー `TurnStart`)
- G013 卵の守り手: 2/3 → **1/2**(卵が確実に孵るようになったため、出す本体を軽く)
- G014 竜人の長: 3/3 → **2/3**(子竜が並びやすくなったため、全体強化の本体を軽く)

竜族は目標(50% ± 3%)をまだ少し上回る。オーナーの実プレイの感触を見て再調整する。

## AI の修正(同時に実施)
守護付きの卵を試したところ、1 手読みの貪欲 AI の弱点が 2 つ見つかった。どちらも `AiTuning` で調整できる。
- **守護を割らずに固まる**: 「割ると相手に子竜が出る」評価の悪化しか見えず、守護の向こうの打点を評価できなかった
  → 守護に塞がれた打点をペナルティにする(`BlockedByWard = 0.5`、`--ai-ward`)
- **「後で孵る」カードを出さない**: ラストワードで出るフォロワーを評価していなかった(0/1 の卵を一度もプレイしない)
  → ラストワードの召喚先の (攻撃力 + 体力) × 0.5 を加点(`LastWordsSummon = 0.5`、`--ai-lwsummon`)

旧カードのままで AI だけを変えた場合、クラス別勝率の変化は ±1.5% 以内。
