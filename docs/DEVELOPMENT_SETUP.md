# 開発環境・プロジェクトセットアップ手順書 (Phase 0)

本ドキュメントは、2人開発におけるUnity環境の統一およびプロジェクト初期設定をまとめたものです。

---

## 1. 推奨Unityバージョン

- **推奨バージョン**: `Unity 2022.3 LTS` または `Unity 6 (6000.0 LTS)`
- **テンプレート**: 2D (Core / URP 2D)

---

## 2. 必要なUnityモジュール

Unity Hubの「Installs」タブから、対象のUnity Editorバージョンに対して以下のモジュールを追加インストールしてください。

- **Android Build Support**
  - Android SDK & NDK Tools
  - OpenJDK

※ iOS (iPhone) 向けビルドは現フェーズでは対象外です。

---

## 3. ディレクトリ構成

プロジェクトは複数のミニゲームを共存させる構成としています。

```text
Assets/
├── _Project/
│   ├── Common/              # ミニゲーム共通基盤 (Phase 1)
│   │   ├── Scripts/         # 画面遷移・Audio・共通UI・マネージャー
│   │   ├── Scenes/          # タイトル・メニュー・共通シーン
│   │   ├── Prefabs/         # 汎用UIパーツ、ダイアログ等
│   │   ├── Audio/           # 共通BGM / SE
│   │   └── UI/              # 共通UIスプライト・フォント・スタイル
│   │
│   └── Games/               # 各ミニゲームフォルダ
│       └── 01_Soccer/       # 第1弾: 2Dサッカーゲーム
│           ├── Scripts/     # サッカーゲーム固有ロジック
│           ├── Scenes/      # サッカーゲームプレイシーン
│           ├── Prefabs/     # 選手・ボール・ゴール等プレハブ
│           ├── Sprites/     # サッカー用スプライト・ピッチ画像
│           └── Audio/       # サッカー用固有SE
│
└── Plugins/                 # サードパーティライブラリ用
```

---

## 4. Git・ファイル管理ルール

- **`.gitignore`**: プロジェクトルートに配置済み。Unityの一時キャッシュ（`Library/`, `Temp/`, `Logs/`等）やIDE設定は自動的に除外されます。
- **`.meta` ファイル**: Unityの仕様上、Assetを追加・変更した際に生成される `.meta` ファイルは**必ずセットで管理**してください。
- **コンフリクト防止**: シーンファイル（`.unity`）やプレハブ（`.prefab`）の競合を避けるため、プレハブベースで作業を分担することを推奨します。
