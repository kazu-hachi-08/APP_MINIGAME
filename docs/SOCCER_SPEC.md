# 第1弾ミニゲーム：2Dサッカーゲーム 仕様書

## 1. 概要

本ゲームは、「週末2人開発 2Dミニゲームプロジェクト」における第1弾ミニゲームとして開発する。

プロジェクト全体として複数のミニゲームを開発する方針であり、本ゲームはそのうちの1タイトルとして位置付ける。

---

# 2. 基本仕様

| 項目         | 内容                    |
| ---------- | --------------------- |
| ゲームジャンル    | 2Dサッカー                |
| 視点         | 見下ろし視点（Top-down View） |
| グラフィック     | 2Dスプライト               |
| プレイヤー      | 1人                    |
| チーム人数      | 11 vs 11              |
| 対象プラットフォーム | Android / iPhone      |
| エンジン       | Unity                 |
| 言語         | C#                    |

---

# 3. MVP方針

最初から本格的なサッカーゲームを目指さず、**ゲームとして成立する最小限の機能**を実装する。

## MVP必須機能

```text
✓ 11 vs 11
✓ 見下ろし2D
✓ 選手移動
✓ ボール
✓ パス
✓ シュート
✓ ゴール
✓ 得点
✓ 簡易AI
✓ 選手自動切り替え
✓ Android動作
✓ iPhone動作
```

## MVP対象外

以下は第1弾では原則として実装対象外とする。

```text
△ ファウル
△ オフサイド
△ コーナーキック
△ フリーキック
△ PK
△ イエローカード
△ レッドカード
△ スタミナ
△ 選手能力値
△ フォーメーション変更
△ オンライン対戦
△ キャリアモード
△ リプレイ
```

必要性が確認できた場合のみ、MVP完成後に追加する。

# 5. プレイヤー

## 5.1 操作対象

プレイヤーは自チームの選手1人を操作する。

基本仕様では、ボールに近い自チーム選手を操作対象とする。

```text
             ⚽
              │
       ┌──────┼──────┐
       ↓      ↓      ↓
     5m      8m     12m
    Player A Player B Player C
       │
       ↓
  Player Aを操作
```

## 5.2 選手切り替え

初期実装では自動切り替えを基本とする。

余裕がある場合、手動切り替えを追加する。

```text
自動切り替え
      +
手動切り替え
```

# 6. プレイヤー操作

## 6.1 基本操作

以下の操作を実装する。

* 移動
* パス
* シュート
* 選手切り替え

## 6.2 入力システム

Unity Input Systemを使用し、ゲームロジックと入力方法を分離する。

```text
             Input System
             /          \
            /            \
      キーボード        タッチ操作
           │                │
           └──────┬─────────┘
                  ↓
          Player Controller
                  ↓
               Player
```

開発初期はPCのキーボードで操作し、後からスマートフォン向けタッチ操作を追加する。

## 7.1 基本機能

* ボールの移動
* 選手との接触
* パス
* シュート
* ゴール判定

## 7.2 MVP時の簡略化

最初は複雑なボール物理を実装しない。

### シュート

```text

  ↓
```

# 11. NPC / AI

操作対象以外の選手は簡易AIで制御する。

## 11.1 ポジション維持

各選手に基準ポジションを設定する。

```text
基準ポジション
      ↓
現在位置との差を計算
      ↓
基準位置へ移動
```

## 11.2 ボール追従

ボールとの距離やゲーム状況に応じて、ボール方向へ移動する。

```text
ボールが近い
    ↓
ボール方向へ移動

ボールが遠い
    ↓
基本ポジションを維持
```

## 11.3 攻撃・守備

自チームの攻撃・守備状況に応じて、基準位置を簡易的に変更する。

```text
自チームが攻撃
    ↓
少し前へ移動

相手チームが攻撃
    ↓
自分のポジションへ戻る
```

高度な戦術AIはMVPの対象外とする。
